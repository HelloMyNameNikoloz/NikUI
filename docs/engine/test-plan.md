# Engine test plan — P0 R08 review

2026-11-20, Codex. This is a test specification, not a claim that the proposed suites exist or passed. Existing tests are named explicitly below. `engine-*` suites/helpers remain proposed P1/P2 work except `engine-protocol-v2.test.js`, shared W corpus and Swift `ProtocolV2FixtureTests`, which establish fixture consistency only. R07/R08's `engineConfig.test.js` covers the injected configuration seam, not full T02/T03/T06 or a service adapter. [Architecture v2](architecture.md) and [D1–D27](decisions.md) define the design. [Protocol v2](protocol-v2.md) is authoritative for wire values. Current measured evidence is in [the P0 gate](p0-gate.md).

## Runner and evidence rules

`npm test` is `node test/run.js`. The dependency-free runner finds only top-level `test/*.test.js`, sorts filenames, requires each module in one process and awaits its exported function. `suite(name)`, `check(name, condition)` and `checkEqual(name, actual, expected)` are globals; equality uses JSON serialization, so normalize only irrelevant nondeterminism. `node test/run.js engine` filters filenames by substring, including both `engineConfig.test.js` and hyphenated suites; it does not filter suite/check names. A thrown error aborts the run; a false check records failure and continues. Before loading any suite the runner always replaces `NIKUI_KEEPER_DIR` with a fresh 0700 temporary directory, even if inherited; default links must never find a live keeper. Explicit fixture links use their own temporary roots.

New files follow the existing form:

```js
'use strict';
module.exports = async function () {
  suite('engine receipts');
  // Build an isolated fixture; perform an operation; inspect independent effects.
  // checkEqual('a duplicate does not dispatch again', provider.calls, [original]);
  // Dispose in finally, including after a failed check or thrown setup error.
};
```

Reuse patterns from `hub.test.js` (recording transports and injected host), `codexCommands.test.js` (PassThrough JSON-RPC fake), `transport.test.js` (fake WS/drafts), `durable.test.js` (new object reopening real disk), and `keeper.test.js` (private keeper dir/fake Claude). `helpers/vscode-stub.js` supplies `fakeContext`, separate mementos and SecretStorage/change events; `install()` is cached process-wide. Two calls to `install()` do not make two independent editors. Use explicit adapters/contexts or separate children for that test, and isolate the no-VS-Code test in a clean process.

Preserve `test/run.js` discovery, assertions and failure semantics; isolation fixes such as R07/R08's keeper root are required. Do not replace these assertions with a new framework or weaken legacy expectations to accommodate extraction. Save/restore test-local globals, environment, module hooks and timers in `finally`; browser tests should use separate VM realms where possible. New automatic tests must run on a clean checkout with synthetic credentials and no installed VS Code, provider account, tailnet, app signing or hardware. No environment-dependent skip may disguise an untested P1 behavior.

Launchd/browser/device checks live in separate `*.check.js` scripts or manual runbooks, not the runner's automatic glob. Use the existing `helpers/skip.js` convention for missing prerequisites; a gated run sets `NIKUI_REQUIRE_CHECKS=1`, making an unrun check a failure. Swift tests run with `swift test --package-path app/iphone/NikCore`; wire changes require both Node and Swift results. Existing real-loopback Swift coverage is opt-in: use `NIKCORE_LOOPBACK_TESTS=1 swift test --package-path app/iphone/NikCore` for the integration gate and verify those tests actually ran. A sandbox refusing sockets leaves that gate unrun. Swift fixture tests resolve the same repository directory relative to `#filePath`; do not maintain a second copy of vectors.

Evidence records include source revision, test IDs/vector counts, command, exit status, runtime/OS/bundle identity and sanitized output. A stub pass establishes only its stated level. Launchd, real Keychain, phone and hardware gates remain pending until their own records exist. R05 baseline: 3378/3378 Node checks. Every round runs T01; fixture-child signals are permitted, while live user NikUI/keeper/claude/codex processes are never controlled.

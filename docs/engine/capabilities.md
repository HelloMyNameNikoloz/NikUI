# Capability matrix — current clients and remote API

Snapshot: `132b3c5d5723598699e4ae09176699bfcc4f26f6`, branch `mac-engine`, 2026-11-20. Verified from handlers **and** client action sites. This is current behavior, not the planned Mac feature set. `C` = Claude; `X` = Codex. `✓` = exposed UI; `△` = limited/conditional; `—` = no exposed UI; **API** = remote handler exists but supplied client has no UI. Every mutation from a paired device requires control unless a row says otherwise. VS Code's own webview is trusted; a loopback browser with LocalKey is a local seat.

“Browser” means HTML served by `RemoteServer` (`/`, `/s/<id>`), **not** the bundled Capacitor shell opened in a desktop browser. Android uses `app/shell` plus shared `media`; iPhone means **native SwiftUI `app/iphone`**, not the older Capacitor iOS target still in `app/ios`.

**Mac desktop column: — for every action below.** No production Mac client exists in this snapshot or R08. P2 supplies only the enrolled menu/status/start/stop/logs client and local bridges; the daily-use transcript/composer UI is P3, after P3-G0. `spike-app` is a service/signing probe, and a simulated Mac seat is not exposed UI. P1-02's config seam and R08's inbox fallback do not add wire capabilities.

Concurrent P1 requester plumbing now passes origin context through hub/host calls and Codex fork events; the source anchors/tables below remain the baseline. There is still no enrolled editor registry, full routing policy or headless machine host. Treat that plumbing as partial P1-03 evidence, not a new Mac client or management capability.

## Gaps that affect the extraction

| Gap | Evidence / practical boundary |
| --- | --- |
| Served browser Home has no `.bar`, while `buildChrome()` requires it | `src/remote.js:649` emits `.home-head`; `media/home.js:737` returns when `.bar` absent. The supplied creation/view/provider/organize chrome therefore does not mount on `/`. The handler exists and the shell exposes it; do not claim full browser parity. This is a static wiring finding, not a browser execution test. |
| Core lifecycle/folder/history management is absent from wire | Fleet dispatcher `src/remote.js:1011` plus conversation dispatcher `src/hub.js:381` have no rename/process-stop/restart/remove/folder-CRUD/order/history-delete cases. Add contract before replacing editor as engine owner. |
| An interrupt is not close/remove/restart | Native “Stop” sends interrupt; editor `nikui.stop` closes/removes and `nikui.sleep` only stops process. Preserve vocabulary and provider semantics. |
| UI authority is still a local/editor distinction, not capabilities | `src/hub.js:208`, `src/slackRoom.js:286`, `src/remote.js:1359`; new Mac device needs server-assigned local capabilities, not a self-declared `kind`. |
| Editor actions use window host singleton; requester not passed | `src/host.js:22`, `src/host.js:293`, `src/hub.js:644`, `src/hub.js:654`; no editor registration, workspace coverage, routing, expiry or unavailable response contract. |

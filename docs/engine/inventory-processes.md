# Processes, sockets, servers and timers — baseline and R08 delta

Snapshot: `132b3c5d5723598699e4ae09176699bfcc4f26f6`, branch `mac-engine`, 2026-11-20. Static code trace; no process was launched/stopped for verification. Scope: engine `src/**/*.js`, its native helpers, and the client transports relevant to reload/recovery. Browser animation/debounce timers are presentation details; the server-side timers, including bounded shutdown/retry timers, are below. Source references are repository-relative.

The snapshot statement and line anchors refer to that baseline inventory. R07/R08 changes: keeper default root honors `NIKUI_KEEPER_DIR`, and the runner always supplies a private fresh root. R08's notification inbox now handles synchronous/asynchronous `fs.watch` failure with a nonpersistent 200ms `fs.watchFile` poll of that window's inbox only; disposal closes both paths. This fixes a real asynchronous EMFILE crash without bypassing click consumption/routing. [R08 evidence](evidence-r08.md) runs spawned fixtures only; service-generation ownership remains future work.
